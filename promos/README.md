# Plugin Store promo images

Marketing images for the Publishr listing on the Craft Plugin Store, in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-publishr](https://justinholt.com/plugins/craft-publishr).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `publishr-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome,
then downsampled so the type stays crisp). **Promos are JPEG, never PNG** — Chrome can only write
PNG, so `build.sh` converts with `sips` at quality 90 and deletes the intermediate.

Chrome sometimes exits non-zero *after* writing the screenshot ("Teardown watchdog expired"), which
killed the chunky-derived script under `set -e`. This one judges each run by whether the PNG exists.

## The CP screens are hand-built

Publishr is not installed on the plugin-testing harness, so slides 2–6 are HTML/CSS mocks rather
than captures. They are built from the real templates (`src/templates/*.twig`) with
`src/web/assets/cp/dist/publishr.css` copied in, Craft 5's own gray scale and hairline values, and
the plugin's own strings — lane abbreviations (`due`/`pub`/`exp`/`rev`), gate messages
("412 words — 600 needed", "RedPen couldn't review this piece."), the `Not yet: …` refusal. Each
screen is written at native CP pixel sizes and scaled with `zoom`.

The sample data agrees across slides: a pip's colour is its *stage*, so a piece is the same colour
on the calendar as on the board and in the overview. Change one and check the others. When the CP
can be captured, real screenshots can replace any frame without touching the copy.

## Palette

Accent `#4A4FA8` from the icon's tile. `#ABAFF6` is the same indigo lifted far enough to read as
small text on the dark ground (eyebrows, bullets); `#7479D6` sits between them in the title
gradient. The family `#ffd166` gold is used sparingly. Jersey 20 for display, Inter for body.

## The watermark

`assets/watermark.svg` is `../src/icon-mask.svg` — the calendar glyph with the tile stripped —
filled white at 3% opacity. The glyph is itself a rounded rectangle, so it is pushed down and right
until its right and bottom edges are off the slide: what shows is a binding ring and one rounded
corner of the header band, never a closed box. It is switched off on the cover.

`assets/icon.svg` is a byte-identical copy of `../src/icon.svg`. Re-copy it whenever the icon
changes.

`fonts.css` is generated by `build.sh` and gitignored; don't edit it.
